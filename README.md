# willjackson.uk

Personal portfolio website, built to showcase selected web development work, technical skills and contact details.

## Built with

* Astro
* Tailwind CSS
* TypeScript
* Cloudflare Workers

## Features

* Single-page portfolio layout
* Project cards with screenshots
* Responsive design
* Lightweight image zoom
* Simple structured project/contact data

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```
